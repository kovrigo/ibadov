# Первый запуск лендинга

Урок проводит по странице от сборки до проверок. Нужна рабочая копия репозитория на сервере доски. Все команды запускают из её корня.

## 1. Поставьте зависимости

```
bun install
```

## 2. Соберите и откройте сайт

```
paneweb up
paneweb url
```

- `paneweb up` собирает страницу и показывает её. Сборка сначала запускает три быстрые проверки.
- `paneweb url` печатает адрес сайта. Откройте его в браузере.

## 3. Посмотрите вступление

Страница открывается фильмом заказчика: следы света над Исаакием, рывок камеры, титр «SAINT PETERSBURG». Затем фильм растворяется в Сергея на балконе. Первый экран готов к 7,8 с.

- Коснитесь кадра, нажмите «Пропустить», прокрутите или нажмите клавишу. Готовый первый экран встанет за 0,24 с.
- Обновите страницу. Фильм играет снова: браузер ничего не запоминает.

## 4. Пролистайте главы

Сцены идут по порядку:

1. Первый экран.
2. «Купить / Продать».
3. Стоп-кадр «№1 риелтор Петербурга».
4. Цифры.
5. Партнёры.
6. Финал с кнопкой Telegram и ссылкой на Instagram.

Каждая сцена при входе показывает своё движение.

## 5. Включите спокойную версию

Включите в системе настройку «уменьшить движение» и обновите страницу. Подойдёт и эмуляция `prefers-reduced-motion` в инструментах разработчика.

- Вступления нет.
- Ничего не сдвигается и не увеличивается. Изображения только мягко проявляются.
- Все тексты и кнопка на месте.

## 6. Запустите проверки

```
bun run test:unit
bun run test:html
/usr/local/lib/heavy-gate/heavy-gate browser bun run test:e2e
```

- `test:unit` проверяет тексты, изображения, вступление и правила кода.
- `test:html` проверяет готовую страницу из `dist/`. Ей нужна сборка из шага 2.
- `test:e2e` открывает страницу в Chromium. Ей нужен сайт из шага 2.

## 7. Остановите сайт

```
paneweb down
```
