# Как менять лендинг

Рецепты частых правок. Команды запускают из корня рабочей копии. Цвета, шрифты и движение заданы в `DESIGN.md`: отступать от него можно только с согласия заказчика.

## Изменить текст

1. Согласуйте новый текст с заказчиком. Впишите его в Бриф, раздел «Дизайн», подраздел «Тексты».
2. Все слова страницы лежат в `src/blocks/texts/index.ts`. Измените текст там.
3. Тот же текст впишите в объект `brief` в `src/blocks/texts/tests/texts.test.ts`. Тест сверяет тексты блока с ним дословно.
4. Факты заказчика меняйте только его словами. «№1 риелтор Петербурга» стоит дословно.
5. Проверьте: `bun test ./src/blocks/texts`.
6. Пересоберите сайт: `paneweb down`, затем `paneweb up`.
7. Проверьте готовую страницу: `bun run test:html`.

Длинный текст может не поместиться в кадр. Кадрирование и поля проверяет `tests/e2e/design-check.spec.ts` в браузерных проверках.

## Изменить цветокоррекцию

1. Цветокоррекция — функция `grade()` в `tools/assets/grade.py`:
   - кадры заказчика (`composite`) остаются как есть: их цветокоррекцию заказчик назвал правильной 8 октября 2026;
   - фотографии (`photo`) подводятся к ним: янтарный оттенок 28° в средних тонах, золотые света, насыщенность ×1.22–1.5, кривая `L ** 0.88 * 1.14`.
2. Функция `checks()` в том же файле держит пределы, снятые с трёх кадров заказчика:
   - средний цвет глубоких теней от `#090603` до `#100C0A`, тёплый (R ≥ G ≥ B);
   - насыщенность средних тонов от 0.38 до 0.65;
   - оттенок светов от 15 до 40 (круговое среднее).
3. Новый предел сначала согласуйте с заказчиком.
4. Пересоберите изображения: `uv run tools/assets/prepare.py`. Если `uv` не может прочесть свой каталог Python, задайте ему каталоги в `tmp/`: `UV_CACHE_DIR=$PWD/tmp/uv-cache UV_PYTHON_INSTALL_DIR=$PWD/tmp/uv-python`. Шаг бесплатный и локальный. Он пишет `src/blocks/images/assets/*.webp` и `manifest.json`. При нарушенном пределе он завершается с ошибкой.
5. Проверьте: `bun test ./src/blocks/images`.
6. Пересоберите сайт: `paneweb down`, затем `paneweb up`.

Не запускайте `tools/assets/fill.py`. Он платный, а дорисованный фон уже лежит в `src/blocks/images/assets/prep/`.

## Изменить вступление

1. Шаги и время вступления лежат в `src/blocks/opening/timeline.ts`. Общие длительности движения — `motion.duration` в `src/design/tokens.ts`.
2. Растворение в первый экран начинается до конца файла и кончается после него. Это проверяет `src/blocks/opening/tests/timeline.test.ts`.
3. Движение может менять только положение, масштаб, прозрачность и видимость. Другое не пропустит `tests/motion-properties.test.ts`.
4. Проверьте: `bun test ./src/blocks/opening`, затем браузерные проверки.

## Заменить видео вступления

Исходник заказчика — `src/blocks/opening/assets/source/intro.mp4`. Страница берёт `intro-cut.mp4` рядом. Он собран так (ffmpeg со статической сборкой, без звука, первые 7,0 с — до собственного растворения фильма в вшитый первый экран):

```
ffmpeg -i src/blocks/opening/assets/source/intro.mp4 -t 7.0 -an -vf format=yuv420p -c:v libx264 -preset veryslow -crf 24 -profile:v high -g 48 -movflags +faststart src/blocks/opening/assets/intro-cut.mp4
```

Новое видео длиннее или короче — поправьте `clip` и шаги в `timeline.ts`. Вшитый титр в другом месте кадра — поправьте ширину кадра в вертикальной схеме в `Opening.astro`: титр должен помещаться в ширину экрана.

## Посмотреть вступление ещё раз

Обновите страницу. Браузер ничего не запоминает: фильм играет при каждом открытии. Его нет, если в адресе есть `#`, если страница открыта кнопкой «Назад» и при настройке «меньше движения».

## Собрать для настоящего адреса

```
SITE_URL=https://<адрес сайта> bun run build
```

- Готовый сайт — папка `dist/`: статичные файлы, без сервера.
- Адрес нужен карточке ссылки в мессенджерах. Без `SITE_URL` сборка останавливается с ошибкой `SITE_URL is required to build the link card (absolute og:image URL).`
- Адрес сайта и хостинг пока не выбраны. В репозитории нет настроек выкладки.

## Проверить всё

```
bun run test:unit
bun run test:html
/usr/local/lib/heavy-gate/heavy-gate browser bun run test:e2e
```

`test:html` читает сборку в `dist/`. `test:e2e` открывает сайт, который поднял `paneweb up`.
