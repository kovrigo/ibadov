# Справочник лендинга

## Команды

- `bun install` ставит зависимости.
- `bun run dev` запускает режим разработки Astro. На сервере доски сайт поднимают только через `paneweb up`.
- `bun run build` сначала запускает три проверки, затем собирает сайт в `dist/`. Нужен `SITE_URL`. Проверки:
  - `tests/architecture.test.ts`;
  - `tests/motion-properties.test.ts`;
  - `src/blocks/images/tests/manifest.test.ts`.
- `bun run test:unit` запускает `bun test` по `src/` и обе проверки правил из `tests/`.
- `bun run test:html` проверяет `dist/index.html`.
- `bun run test:e2e` запускает Playwright в Chromium. Адрес сайта берёт из `paneweb url`. Два набора:
  - `layout` — все файлы, кроме `intro`, `calm` и `smooth`;
  - `timing` — эти три, после `layout`, в один поток.
- `paneweb up`, `paneweb down`, `paneweb url` поднимают, останавливают и называют сайт. Настройка — `.paneweb.json`: сборка с `SITE_URL=https://example.test`, затем `astro preview`.
- `uv run tools/assets/prepare.py` заново собирает изображения.

## Настройки

- `SITE_URL` — полный адрес сайта. Без него сборка останавливается: карточке ссылки нужен полный адрес изображения.

## Вступление

- Видео заказчика без звука, затем первый экран. Длится 4,4 с:
  - 0–0,24 с: видео проявляется из тёмного;
  - 2,6 с: титр «Сергей Ибадов»;
  - 3,0–3,9 с: видео растворяется в кадр с балконом;
  - 3,0–4,4 с: кадр с балконом встаёт, масштаб от 1,08 до 1,00;
  - 3,5 с: заголовок, подзаголовок, меню и «Пролистайте».
- Файлы: `intro-wide.mp4` (1280×720, 1,5 МБ) в широкой схеме, `intro-vertical.mp4` (406×720, 0,5 МБ) в вертикальной. Скачивается только нужный, и только когда вступление может играть.
- Касание, колесо мыши, прокрутка или клавиша дают готовый первый экран за 0,24 с.
- Кнопка Telegram во время вступления сразу открывает Telegram.
- Вступление не играет:
  - при настройке «меньше движения»;
  - при экономии трафика или сети 2G;
  - когда в адресе есть якорь `#`;
  - когда в этом браузере вступление уже сыграло или его пропустили;
  - когда слои первого экрана не готовы или видео не пошло за 1,5 с, или страница уже не наверху.

## Блоки

Папки в `src/blocks/`. Уровни описаны в [архитектуре](product/system-architecture.md).

- Уровень 0:
  - `texts` — все слова страницы;
  - `images` — изображения, их описание в `catalog.ts`, файлы в `assets/`.
- Уровень 1:
  - `story` — сцены и их слои;
  - `contact` — кнопка Telegram, полоса на телефоне, ссылка Instagram;
  - `card` — карточка ссылки.
- Уровень 2:
  - `camera` — движение сцен при прокрутке, вспышка стоп-кадра, цифры;
  - `accents` — блик на часах, дым, сигара, дрожание зерна.
- Уровень 3:
  - `opening` — вступление: решение в `gate.ts`, шаги в `timeline.ts`, показ в `motion.ts`.

Под блоками:

- `src/design/` — детали дизайн-системы, общие значения из `DESIGN.md` в `tokens.ts`, шрифты.
- `src/platform/` — каркас страницы в `frame/`, такт движения в `motion-loop.ts`, настройка движения в `motion-setting.ts`.
- `src/pages/index.astro` — сама страница.

## Изображения

- Исходники заказчика: `src/blocks/images/assets/source/`. Кадр со столом — `desk.png`.
- Подготовка: `src/blocks/images/assets/prep/` — дорисованный фон и маски Сергея.
- Готовые изображения: `src/blocks/images/assets/*.webp`, без потерь. Список и sha256 — в `manifest.json`.
- Размеры, отметки лица, купола и часов, ширины и качество AVIF и WebP — в `src/blocks/images/catalog.ts`.
- Инструменты в `tools/assets/`:
  - `prepare.py` собирает все готовые изображения из исходников и `prep/`. Бесплатно, локально.
  - `grade.py` — цветокоррекция Брифа и её пределы.
  - `matte.py` делает маску Сергея. Бесплатно, локально.
  - `fill.py` дорисовывает фон моделью изображений. Платно: $0.134 за вызов, только через маршрут расходов доски.
- Сборка страницы эти инструменты не запускает.

## Проверки

- `src/blocks/*/tests/` — проверки блоков: тексты дословно, изображения по `manifest.json`, шаги вступления.
- `tests/architecture.test.ts` — блок зовёт другой только через его `index.ts` и только на своём или нижнем уровне.
- `tests/motion-properties.test.ts` — движение меняет только transform, opacity, will-change и visibility.
- `tests/html.test.ts` — готовая страница из `dist/`.
- `tests/e2e/`:
  - `intro.spec.ts` — вступление, пропуск, Telegram во время него, возврат назад;
  - `calm.spec.ts` — спокойная версия;
  - `nojs.spec.ts` — страница без скриптов и без изображений;
  - `scripts.spec.ts` — со скриптами: тексты видны, отказ изображений;
  - `phone.spec.ts` — телефон: прокрутка, одна кнопка, полоса, Tab, вес изображений;
  - `design-check.spec.ts` — кадрирование, поля и размер текста на экранах Брифа;
  - `smooth.spec.ts` — плавность: кадр не дольше 100ms при замедленном в 4 раза процессоре.
